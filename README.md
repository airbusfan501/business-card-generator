This is a python terminal application that allows the user to create a simple, modern, and professional business card.
I created this with Canva (for the card template) Pillow (the open-source python library for image processing) and of course Python.

How to use the Business Card Generator:
1: Clone this repository 
2: Install dependencies: 'pip install -r requirements.txt'
3: Run the script 'python3 card.py'
4: Enjoy!
